# منابع داده

## فعال در نسخهٔ اول
- IODA API v2: `bgp`، `ping-slash24` و `merit-nt` برای کشور `IR`.
- endpoint: `/signals/raw/country/IR`
- پارامترهای سیگنال: `from`، `until`، `source` و `maxPoints`.

## منابع آتی
- RouteViews برای شواهد BGP تکمیلی.
- OONI برای اندازه‌گیری‌های عمومی سانسور با cadence و تأخیر مختص خودش.
- RIPE Atlas فقط measurementهای عمومی موجود، تا زمان بررسی محدودیت credit.

برای هر منبع بعدی باید owner، cadence، مجوز، rate-limit، زمان مشاهده، کیفیت، جغرافیا و dedup مشخص شود.


## دامنهٔ پوشش OONI
- API در هر درخواست حداکثر ۱۰۰ رکورد صفحه‌بندی می‌کند؛ Collector تا پنج صفحه برای هر کلاس نتیجه می‌خواند و هر شش ساعت اجرا می‌شود.
- نتایج تأییدشده از ناهنجاری‌های تأییدنشده جدا می‌مانند؛ خطای اندازه‌گیری به‌تنهایی برچسب فیلترینگ نمی‌گیرد.
- شناسهٔ ASN با پیشوند `AS` نرمال می‌شود تا تعداد شبکه‌های مشارکت‌کننده درست محاسبه شود.
- فهرست فقط دامنه‌های مشاهده‌شده در آزمون‌های داوطلبانه را شامل می‌شود؛ پوشش کامل وب یا همهٔ ISPهای ایران ادعا نمی‌شود.
