# منابع دادهٔ NetGuard

## ۱. IODA — شواهد ملی
| سیگنال | مفهوم | cadence مورد انتظار |
|---|---|---:|
| bgp | شبکه‌های IPv4 قابل مشاهده در BGP | ۵ دقیقه |
| ping-slash24 | شبکه‌های IPv4 پاسخ‌گو به پایش فعال | ۱۰ دقیقه |
| merit-nt | IPهای یکتای دیده‌شده در تلسکوپ شبکه | ۵ دقیقه |

- endpoint: /signals/raw/country/IR
- پارامترها: from، until، source و maxPoints.
- تلاش production برای جمع‌آوری هر ۱۰ دقیقه است؛ این برنامه با cadence انتشار خود IODA یکی نیست.
- BGP و Ping شاخص اصلی‌اند؛ Merit شاهد کمکی است و تغییرش به‌تنهایی افت اینترنت را ثابت نمی‌کند.
- دادهٔ این بخش ملی است.

## ۲. OONI Web Connectivity
- API: https://api.ooni.io/api/v1/measurements
- فقط web_connectivity از probeهای کشور IR خوانده می‌شود.
- نتایج confirmed از anomaly جدا ذخیره می‌شوند.
- API در هر صفحه حداکثر ۱۰۰ رکورد می‌دهد؛ Collector تا پنج صفحه برای هر کلاس نتیجه می‌خواند.
- Collector هر ۱۰ دقیقه سه روز اخیر را همگام می‌کند؛ نمای عمومی شواهد ۹۰ روز را خلاصه می‌کند.
- شکست آزمون یا anomaly به‌تنهایی اثبات فیلترینگ نیست.

## ۳. Citizen Lab
- فهرست ایران فقط نامزد آزمون است، نه شاهد اندازه‌گیری.
- دامنه بدون نتیجهٔ OONI به‌عنوان «در فهرست آزمون؛ هنوز نتیجهٔ تازه نداریم» نمایش داده می‌شود.

## ۴. وضعیت جهانی ارائه‌دهندگان
صفحه‌های رسمی Cloudflare، DigitalOcean، Render، Supabase، OpenAI، Anthropic، Hugging Face، GitHub و Google Cloud بررسی می‌شوند.
- Collector هر ۱۰ دقیقه اجرا می‌شود.
- وضعیت کلی Statuspage از وضعیت مؤلفه‌ها جداست.
- عدم پاسخ منبع یعنی «نامشخص»، نه اثبات خرابی سرویس یا اینترنت ایران.
- این داده‌ها جهانی‌اند و دسترسی از داخل ایران را ثابت نمی‌کنند.

## ۵. مراکز دادهٔ ایران
- موجودی اولیه از منابع اپراتور و دایرکتوری‌های شخص ثالث است.
- سطح شواهد هر رکورد جداست.
- probe زندهٔ NetGuard برای سلامت این سایت‌ها در v1 فعال نیست؛ وضعیت عملیاتی نامشخص می‌ماند.

## ۶. قواعد تفسیر
- observed_at زمان مشاهده و collected_at زمان دریافت است.
- موفقیت Collector تضمین‌کنندهٔ مشاهدهٔ تازه نیست.
- دادهٔ غایب صفر نیست.
- freshness، cadence delay، پوشش و طول تاریخچه جدا هستند.
- یک منبع به‌تنهایی علت outage، فیلترینگ یا تحریم را قطعی نمی‌کند.
