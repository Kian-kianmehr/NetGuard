# منابع داده

## فعال در نسخهٔ اول
- IODA API v2: `bgp`، `ping-slash24` و `merit-nt` برای کشور `IR`.
- endpoint: `/signals/raw/country/IR`
- پارامترهای سیگنال: `from`، `until`، `source` و `maxPoints`.

## منابع آتی
- RouteViews برای شواهد BGP تکمیلی.
- OONI برای اندازه‌گیری‌های عمومی سانسور با cadence و تأخیر مختص خودش.
- RIPE Atlas فقط measurementهای عمومی موجود، تا زمان بررسی محدودیت credit.

برای هر منبع بعدی باید owner، cadence، مجوز، rate-limit، زمان مشاهده، کیفیت، جغرافیا و dedup مشخص شود.
